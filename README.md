# 🎮 Cub3D

**Cub3D** is a simplified 3D raycasting game engine inspired by *Wolfenstein 3D*, developed in C using the **MiniLibX** graphics library as part of the 42 Network curriculum. This project focuses on rendering a 3D environment from a 2D map and handling player movement and interaction.

---

## 🎯 Project Objectives

- Implement a 3D rendering engine using raycasting techniques  
- Parse and validate map files with walls, player start position, and objects  
- Handle real-time player movement and rotation  
- Render textured walls and a minimap  
- Manage collision detection and game loop mechanics  

---

## 🕹️ Features

- 3D first-person view with raycasting  
- Player controls: movement (WASD), rotation (arrows)  
- Textured walls and floor rendering  
- Minimap displaying the player and map layout  
- Map file validation and error handling  
- Smooth rendering with FPS control  

---

## 🛠️ Technologies

- C language  
- MiniLibX (graphics library)  
- Raycasting (mathematics and trigonometry)  
- Unix/Linux or macOS environment
